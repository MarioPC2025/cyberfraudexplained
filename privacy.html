Privacy Policy

Effective date: October 23, 2026

This Privacy Policy describes how the Cyber Fraud Explained Publishing Pipeline (the "Tool"), operated by Cyber Fraud Explained ("we", "us"), accesses, uses, stores and shares information. The Tool is a private, in-house application used only by the owner of the Cyber Fraud Explained YouTube channel to publish the channel's own videos.

1. Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also handled in accordance with the Google Privacy Policy.

2. Information we access

When the channel owner signs in with Google (OAuth 2.0), the Tool requests these permissions for the channel's own account only:

  • youtube.upload: to upload videos to the channel;
  • youtube.force-ssl: to set the custom thumbnail and upload subtitle tracks for those videos.

Through these permissions the Tool reads only the basic channel identity (channel name and ID) needed to confirm it is connected to the right channel, and the IDs of the videos it uploads. It does not read comments, subscribers, analytics, viewing history, or any other user's data.

3. How we use information

The information is used only to upload the channel's own videos (always as private, for a final manual review), and to set their title, description, tags, thumbnail and subtitles. It is not used for advertising, profiling, analytics, or any other purpose.

4. Storage and security

The OAuth access and refresh tokens issued by Google are stored only on the channel owner's personal computer, in a local file outside of version control. They are never uploaded to any server, database or third-party service. No personal information is stored by us anywhere else. The Tool has no servers, website accounts or user database.

5. Sharing

We do not sell, rent, or share any information obtained through YouTube API Services with third parties. Video files and their metadata are sent only to YouTube, as part of the upload.

6. Cookies and tracking

The Tool does not use cookies, and it does not place, access or recognize cookies or similar technologies on any device. This website does not use cookies, analytics or trackers.

7. Revoking access and deleting data

Access granted to the Tool can be revoked at any time from the Google security settings page. Once access is revoked, or upon request, the locally stored tokens are deleted within 7 days. Because the Tool stores no other data obtained through YouTube API Services, nothing else needs to be deleted.

8. Children

The Tool is not directed to children and is used only by the adult channel owner.

9. Changes to this policy

If this policy changes, the updated version will be posted on this page with a new effective date.

10. Contact

Questions about this policy: cyberfraudexplained@gmail.com
